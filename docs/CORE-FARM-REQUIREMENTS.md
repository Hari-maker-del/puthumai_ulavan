# Core farmer platform requirements implemented as production data contracts

Operations: field records, crop lifecycle, tasks/calendar, yield comparison.
Resources: inventory, irrigation schedules, equipment logs.
Market/finance: live market architecture, sales log, cost analytics.
Advisory: localized weather, alerts, soil test records.
Community: knowledge articles and community posts.

Rule: no fake prices, weather, inventory, listings, scheme data or farmer records. If a live source is unavailable, show an explicit unavailable state.

Live external API/device verification remains required before production sign-off.
