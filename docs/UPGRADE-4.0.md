# Puthumai Uzhavan 4.0 — Farm Health & Decision Quality

This upgrade focuses on decision quality instead of adding disconnected screens.

## Farm Health Center
A transparent, deterministic score combines:
- crop health
- open high-priority tasks
- active weather/crop alerts
- expense pressure
- farm-data completeness
- weather risk

The score is explicitly presented as decision support, not a scientific crop diagnosis.

## Authentication reliability
Email verification now confirms that a usable verified session exists before the callback is considered successful, reducing redirect races.

## Product direction
The application now has a coherent progression:
Farm context → verified data → intelligence → action → outcome → health/readiness.

The score must never be presented as a medical/scientific certainty or as a guaranteed yield/profit prediction.
